## 3️⃣ 具體實作：vLLM + 量化 + Flash‑Attention

### 3.1 安裝依賴

```bash
# 需要至少 CUDA 11.8
conda create -n llm python=3.10 -y
conda activate llm

pip install "vllm[triton]"  # 用 triton 以啟用 Flash-Attention
pip install --upgrade tiktoken
```

### 3.2 下載量化後的模型

```bash
# 以 4‑bit AWQ 為例 (需要 llama.cpp 或 transformers)
git clone https://github.com/cppl/awq.git
cd awq
python scripts/quantize.py \
  --model_dir /path/to/Llama-2-70b-chat-hf \
  --output_dir /path/to/llama2-70b-awq-4bit \
  --bits 4
```

### 3.3 配置 vLLM 服務

```python
# server.py
import os
from vllm import LLM, SamplingParams
import tiktoken
from flask import Flask, request, jsonify

app = Flask(__name__)

MODEL_PATH = "/path/to/llama2-70b-awq-4bit"
DEVICE_MAP = {"cpu": 0}  # 讓 CPU 負責 0 卡（參數 off‑load）
LLM_INST = LLM(
    MODEL_PATH,
    dtype="bfloat16",          # 4‑bit quant + BF16 前向
    device="auto",
    max_seq_len=32768,
    enforce_eager=False,       # 使用 Flash‑Attention
    gpu_memory_utilization=0.9,  # 90% GPU 內存
)

enc = tiktoken.encoding_for_model("Llama-2-70b-chat-hf")

def build_prompt(user_prompt: str, task: str) -> str:
    system = "You are a senior Python engineer."
    return f"<s>[INST] <<SYS>>\n{system}\n<</SYS>>\n{user_prompt}\nTask: {task} [/INST]"

@app.route("/optimize", methods=["POST"])
def optimize():
    data = request.json
    context = data["context"]
    task = data.get("task", "Improve code.")
    prompt = build_prompt(context, task)

    if len(enc.encode(prompt)) > 32768:
        return jsonify({"error": "Prompt too long"}), 400

    params = SamplingParams(
        temperature=0.2,
        top_p=0.95,
        max_tokens=2048,
        stop=["</s>"],
    )
    output = LLM_INST.generate(prompt, params)[0]
    return jsonify({"answer": output.outputs[0].text.strip()})

if __name__ == "__main__":
    app.run(host="127.0.0.1", port=8000)
```

> **說明**
> - `dtype="bfloat16"` + 4‑bit AWQ 讓 GPU 只需要 **≈ 20 GB**。
> - `gpu_memory_utilization=0.9` 允許 vLLM 佔 90% VRAM，保留 10% 供 Flash‑Attention 需要。
> - `enforce_eager=False` 啟用 Triton/Flash‑Attention。
### 3.4 減少 CPU RAM

```bash
export OMP_NUM_THREADS=4        # 只用 4 個 core
export MKL_NUM_THREADS=4
export NUMEXPR_MAX_THREADS=4
```

在 Flask 程式啟動前執行以上環境變數。
此外，將 `prompt` 切成 4‑8k token 的小 chunk，逐段推理，減少一次性佔用的 RAM。

## 4️⃣ PyCharm  Flask + SSE

- **Flask**：可以用 `flask-sse` 或`Flask-SocketIO` 來把結果逐步推送回 IDE。
- **SSE (Server‑Sent Events)** 只需要一個簡單的端點，Python 端在生成 LLM 響應時把每段結果 `eventsource` 送出去。
- **PyCharm 插件**：你可以在任何 PyCharm 版本安裝插件，並把插件配置成呼叫本地 Flask SSE 端點。
- **版本**：只要你能安裝 `python` 和 `pip`，**任何版本的 PyCharm（Community / Professional）** 都能運作。
  - 如果你想使用 IntelliJ 內建的 *Remote Python Interpreter*，也能把 Flask 服務部署在本機或遠端，PyCharm 只需連線即可。

> **範例**：Flask SSE endpoint
> ```python
> @app.route('/stream')
> def stream():
>     def generate():
>         for part in LLM_INST.generate(prompt, params, stream=True):
>             yield f'data: {part.outputs[0].text}\n\n'
>     return Response(generate(), mimetype='text/event-stream')
> ```

> **PyCharm 插件**（簡化版）
> - 監聽 `Ctrl+Alt+O`
> - 呼叫 `http://127.0.0.1:8000/stream`
> - 將收到的 SSE 資料直接貼在編輯器底部或彈出窗口。
