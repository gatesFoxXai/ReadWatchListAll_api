# Markdown 反斜線指南 (2026 年版)

在 Markdown 中，反斜線（`\\`）常被用來 **逃脫** 特殊字元，讓它們以純文字顯示。以下說明如何在不同情境下正確使用，並確保 Copilot、模型與 VS Code 記憶體 (memory) 能正確辨識。

## 1. 基本逃脫

```markdown
要顯示星號 (*)，使用 \\* 例如：\\*這是星號*\
```

結果會呈現：`*這是星號*`

## 2. 代碼區塊內的反斜線

在三重反引號（```）的程式碼區塊裡，**不需要** 再額外逃脫，除非你要在字串中保留兩層反斜線。

```markdown
```python
path = "C:\\Users\\name\\file.txt"
```
```

## 3. 表格中的反斜線

Markdown 表格的儲存格會把 `|` 當成欄位分隔符號，若要在儲存格內顯示 `|`，必須先逃脫，再在必要時再加上反斜線。

```markdown
| 語法 | 說明 |
|------|------|
| a \\| b | 這裡的 `|` 被逃脫 |
```

## 4. 與 Copilot / 模型記憶體的整合

- **記憶體標註**：在需要模型記憶的段落前加入 `<!-- @memory:start -->`，結束時加入 `<!-- @memory:end -->`，模型會將該區塊納入長期記憶。
- **範例**：

```markdown
<!-- @memory:start -->
在此段落說明如何在 VS Code 中使用反斜線設定自訂快捷鍵。
<!-- @memory:end -->
```

## 5. 常見錯誤與排除

| 錯誤情境 | 原因 | 解決方式 |
|----------|------|----------|
| 反斜線不顯示 | 少了雙反斜線 | 使用 `\\` 逃脫 |
| 代碼區塊內路徑錯誤 | Windows 路徑未雙重逃脫 | `C:\\Users\\...` |
| 表格斷行 | `|` 未逃脫 | `\\|` |
